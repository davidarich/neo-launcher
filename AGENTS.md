# AGENTS.md

## Rules
1. Do not try to build or compile the project.
2. Do not try to run the project.
3. Do not refactor existing code unless explicitly told. Making changes to expand functionality is OK.
4. Make sure there are no errors before finishing.
5. Trust the output of rust-analyzer. rust-analyzer is always right.
6. Fetch documentation from docs.rs if unsure about a dependency. Do not try to use the terminal.
7. Ask the end user to manually install required dependencies.
